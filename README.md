# PustakaKu

Aplikasi web pencatatan buku perpustakaan SMA.
Dibuat dengan Next.js (App Router), TypeScript, Tailwind CSS, Prisma, dan SQLite.

## Cara menjalankan

```bash
npm install
npm run dev
```

Buka http://localhost:3000

## Halaman

| Rute | Keterangan |
|---|---|
| / | Landing page |
| /buku | Daftar buku dan pencarian |
| /buku/[id] | Detail buku |
| /buku/baru | Form tambah buku |
